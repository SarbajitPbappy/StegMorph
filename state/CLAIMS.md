## V3-H26 data-format addendum and overlap result (2026-11-15; after the download and before any detector run; scripts data/brats_raw/channel_overlap.py, msd_fp.py; results data/brats_raw/overlap_rot180.json)
Format: 57,195 slice files, 369 volumes (slices 0 to 154); each file holds image (240, 240, 4) float64 and mask (240, 240, 3) uint8 (the masks are never read). Each volume is z-score normalised over the whole volume: the background is one constant negative value equal to the volume minimum (about -0.5 to -0.65), so the images are skull-stripped but not zero-valued.
Channel order, from the data: a z-scored 32 x 32 block-mean fingerprint of slice 80 was matched against the same fingerprint of all 484 MSD volumes in all four MSD channels (FLAIR, T1w, T1gd, T2w). For the 262 BraTS volumes that match an MSD case, every BraTS channel matches exactly the MSD channel with the same index (262 / 262 on the diagonal, none off it). The BraTS channel order is therefore FLAIR, T1w, T1gd, T2w, and CHANNEL = 3 is T2.
Orientation: the match needs a rotation of the .h5 slice by 180 degrees (np.rot90 twice) relative to the MSD array; the cohort is rotated by 180 degrees so that it has the orientation of IXI and MSD. This changes no rule.
Intensity rule (adaptation, same meaning as the MSD rule): the pre-registered rule scales by the 99.5th percentile of non-zero raw voxels. In the z-scored files the background is the volume minimum, so the equivalent is (z - min) / (P99.5 of values above the minimum - min) * 255, because z is an affine function of the raw values and the raw background is zero.
Overlap with MSD (rule as pre-registered, with the fingerprint test because normalisation differs, so bit identity cannot be tested): 262 of 369 volumes (71.0%) match an MSD case with correlation 1.0000 in all four channels; the highest correlation among the other 107 volumes is 0.9882, so 0.99 separates the two groups cleanly. The 262 matches are 262 distinct MSD cases (of 484). The 262 overlapping volumes are excluded. 107 non-overlapping volumes remain (at least 100, so the rule keeps all of them: cohort size 107, not 120).
Consequence for the central question: the cohort is independent of MSD only after the exclusion, and it is 107 patients, 29% of BraTS 2020 training. The split by patient is int(0.6 * 107) = 64 / 21 / 22 (train / validation / test) with default_rng(2026). The numbers of patients and slices are in the split manifest. With 22 test patients the bootstrap intervals will be wider than for MSD (73 test subjects); this is stated and not corrected.
No other rule of the pre-registration changes.
