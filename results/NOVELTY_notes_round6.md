## PART 1. NOVELTY

### 1.1 Texture attention-guided adaptive LSB (Alrawashdeh et al.), 55 pp.  [CLOSEST NEW PAPER]
- Title (p.1): "Texture attention-guided adaptive LSB steganography with U-Net model and optional GA tuning integrated with ablation study".
- Authors (p.1): Rana Alrawashdeh, Mahfuzur Rahman, Ahmed Aljughaiman, Mahmood Niazi.
- Venue: Scientific Reports, marked "Article in Press" (p.1). Volume/pages not printed. Received 3 Nov 2025, accepted 27 Aug 2026; "(c) The Author(s) 2026".
- DOI as printed: https://doi.org/10.1038/s41598-026-69569-1
- Pixel/location selection: ResNet50 texture map fused with a distance-transform map gives an attention map; a U-Net predicts it; attention sets per-pixel LSB depth. "adaptive bit allocation between 1 and 4 Bits Per Pixel (BPP)" (p.1). Rule: "low-attention areas (below 0.3) receive only 1 bit ... high-attention regions (above 0.8) receive up to 4 bits" (p.13). GA tunes thresholds and bit levels: "weighted objective function incorporated ... capacity (w=0.40), PSNR (w=0.35), and SSIM (w=0.25)" (p.16). The GA fitness contains no detectability term. Key-based/random location selection: not found in text (no stego key or seeded index permutation is described).
- Datasets: BOSSBase covers, "a single image from the USC-SIPI dataset (Peppers image) is used as the secret image" (p.10). Natural grayscale; not medical, no MRI, no subjects (the only mention of "medical" is a description of USC-SIPI content, p.10). Subject-level split: not applicable / not found in text. Splits: U-Net "Train (160) / Validation (40) / Test (200, independent)" (p.13); overall pipeline "training (307 images, 40%), validation (76), independent test (386)" with "fixed random seed (42)" (p.16). Ablation uses N = 384 images per condition (p.22).
- Security evaluation: CNN steganalysers only. "three DL-based steganalyzers, namely Xu-Net, SR-Net, and Ye-Net" (p.40). No SRM, SPAM, RS or ensemble-classifier detector in the experiments (SRM/SPAM/DCTR/GFR appear only in related-work text, p.4, p.5, p.46). Protocol: "Up to 400 matched cover-stego pairs"; "randomly divided into 70% training and 30% testing" with seed 42; trained 30 epochs (p.40). Test set 232 images (116 cover, 116 stego). Result: accuracy 50.00%, AUC 0.500, EER 50.00% for all three at 0.40 BPP target (Table 27, p.44). The confusion matrices are degenerate (e.g. Xu-Net cover recall 9.48%, stego recall 90.52%, p.40), i.e. the detectors predict almost one class; the paper itself says the FP/FN rates "coincide at the level expected from random discrimination" (p.43).
- Security reported only for the Full Model: Table 27 lists Xu-Net, Ye-Net and SR-Net "for Full Model" (p.44). No steganalysis of the ablation variants, Fixed LSB or the edge baseline: not found in text.
- Random-key / random-location baseline under a trained steganalyser: not found in text. The ablation conditions are Fixed LSB, GA Only, Heuristic/Handcrafted/Predicted Attention Only, each + GA, Full Model, and an Edge_Adaptive_Baseline (+GA) (pp.20-31, p.49-50). None is a random-location control, and all are compared on PSNR/SSIM/capacity/time, not detectability. Note that the reported "Fixed LSB" has the same realised payload as the GA variants (262144 bits).
- Matched modification count: "All methods were evaluated using the same realized payload" (p.22), i.e. equal payload only; no matched number of modified pixels/changes across selection rules. Attention-only variants differ in capacity (e.g. 476,413 vs 262,156 bits, p.26 table), so counts are not matched.
- Seeds / CIs: 95% CIs are given for PSNR, SSIM, IF, capacity, BER and timing (e.g. p.22 table, N=384), but these CIs are over images, not over seeds, and none for AUC/accuracy. Limitation stated: "the current evaluation relies on a single random seed and does not quantify variability across multiple independent training and optimization runs" (p.51). The security result has no CI or repeats.
- Self-stated limits relevant to us: "security analysis was limited to the selected CNN-based steganalyzers ... does not establish resistance against all ... steganalysis techniques" (p.50, paraphrase of text); future work lists "additional state-of-the-art steganalyzers, larger benchmark datasets, and cross-dataset evaluation" (p.51).
- VERDICT: does NOT pre-empt our narrow claim (partly relevant only as context). It has a GA, an ablation and CNN detectors, but: natural images not medical, no subject-disjoint MRI, no random-key control, no operator/modification-matched control, no feature-based detector (SRM/SPAM), security only for the proposed model at chance (uninformative, degenerate confusion matrices), a single seed, no CI on detection. Pre-emption: not.

### 1.2 Secure medical image steganography by EH-MB (Ambika and Biradar), 17 pp.
- Title (p.1): "Secure medical image steganography through optimal pixel selection by EH-MB pipelined optimization technique".
- Authors (p.1): Ambika and Rajkumar L. Biradar.
- Venue: Health and Technology (2020) 10:231-247 (footer, p.1; page footer p.9 "Health Technol. (2020) 10:231-247 239"). Received 17 Sep 2018, accepted 27 Dec 2018, "Published online: 16 January 2019" (p.1). Year: 2019 online (copyright line), 2020 volume.
- DOI as printed: https://doi.org/10.1007/s12553-018-00289-x
- Pixel selection: 2-level DWT; Elephant Herding + Monarch Butterfly optimisation picks pixels in high-frequency bands. "uses a fitness function that depends on the cost function, which calculates the edge, entropy, and intensity of the pixel" (abstract, p.1); F = sum P*C with C = (B+E+I)/3 (eqs. 19-20, p.9). No stego key or random location: not found in text.
- Datasets: "medical database [28] was applied" (p.10); reference [28] is Virupakshappa and Amarapur (brain-tumour MRI segmentation work), not a steganalysis dataset. "we utilized five medical images" (p.10). Fig. 4 lists "Barbara, Boat, Foreman, House, Lena, Peppers" as input images. Subject-level split: not found in text (no training/test, no learned detector).
- Security evaluation: none. Metrics are PSNR, MSE, NCC, AD, SC, MD, NAE (p.10-12). No RS, SRM/SPAM, CNN or AUC. Conclusion states encryption/security is future work: "we have planned to inbuilt some data encryption techniques to increase the security level" (p.17). "statistically undetectable" appears only in the introduction as a general property (p.2).
- Random-key/random-location baseline: not found in text. Comparisons are with EH, MBO and other published pixel-selection methods on PSNR etc. (Tables 1-8).
- Matched modification count: not found in text. Seeds/CIs: not found in text.
- VERDICT: Pre-emption: not (a "security" paper in title only; imperceptibility metrics only).
